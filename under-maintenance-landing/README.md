# Under Maintenance Landing Page

This project is an interactive "Under Maintenance" landing page for a portfolio website, featuring a programming-like interface. The main message displayed is "CV Engineer Under Construction".

## Project Structure

```
under-maintenance-landing
├── src
│   ├── index.html        # Main HTML document for the landing page
│   ├── styles
│   │   └── main.css      # CSS styles for the landing page
│   └── scripts
│       └── main.js       # JavaScript for interactive features
├── package.json          # npm configuration file
└── README.md             # Project documentation
```

## Getting Started

To set up and run the landing page locally, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/vanowarna/vanowarna.github.io.git
   cd under-maintenance-landing
   ```

2. **Install dependencies** (if any):
   ```bash
   npm install
   ```

3. **Open the landing page**:
   You can open the `src/index.html` file in your web browser to view the landing page.

## Features

- Displays a clear message indicating that the CV is under construction.
- Interactive programming-like interface to engage visitors.
- Responsive design to ensure a good experience on various devices.
